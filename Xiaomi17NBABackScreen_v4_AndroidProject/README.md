# 小米 17 Pro Max 妙享背屏 · NBA 实时比分 v4.0

## v4.0 新增：球队 Logo 主色得分环绕灯效 + 全套 OLED 护屏优化
1. **自动提取 Logo 主色**：`LogoColorExtractor` 实时扫描当前显示球队的 Logo 像素，按色相面积统计占比最大的主色调（如尼克斯自动提取尼克斯橙、湖人提取湖金黄、凯尔特人提取凯尔特绿、马刺/篮网自动匹配柔和银灰），保证灯效色调与 Logo 完全一致。
2. **1.85 秒整屏环绕流光**：任一球队得分时，在背屏边缘触发 1.85 秒三层柔和流光环绕（快入 -> 旋转呼吸 -> 渐隐归零），峰值亮度控制在约 65%（纯蓝光系额外降至 58%），绝不常亮不伤屏。
3. **全套 OLED 防烧屏机制**：
   - 比分改用降亮度浅灰白（`#CCCCCC` / `#6E7686`）替代刺眼纯白；
   - 记分牌内容每 60 秒自动进行 ±3px 平滑像素微移；
   - 支持主界面一键调节背屏护屏亮度（35% / 50% / 65% / 80%），同步作用于窗口亮度与 OLED 像素不透明度；
   - 主界面新增「测试客队/主队主色灯效」按钮，随时预览背屏流光效果。
