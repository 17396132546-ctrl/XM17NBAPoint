# 小米 17 Pro Max 妙享背屏 · NBA 实时比分 v2.0

## v2.0 升级内容
1. **3 秒级实时同步**：切换为 NBA 官方 CDN 主源（ESPN 自动容灾兜底），比赛进行中默认每 3 秒自动刷新，主界面可随时切换 `3秒实时 / 5秒标准 / 15秒省电`。
2. **暂停 / 犯规 / BONUS 全量展示**：
   - 自动解析 `todaysScoreboard`、`boxscore` 与 `playbyplay` 实时接口；
   - 显示两队**剩余暂停数**、**本节犯规数**及**犯满（BONUS）**红字提醒；
   - 背屏底部新增**实时动态高亮条**：请求暂停时变黄高亮（`⏸️ 暂停中`），犯规时变红高亮（`🚨 犯规`），三分/得分变蓝提示。
3. **修复上一版所有 Bug**：
   - 适配状态栏高度，彻底解决标题遮挡与按钮文字截断；
   - 未开赛时间自动转为手机本地时间（告别 `EST`）；
   - 新增悬浮窗 `Presentation` 直投背屏（附带 `miui.rear.policy=1` 策略声明）与全屏记分牌模式（支持配合 MRSS 一键切背屏）。
