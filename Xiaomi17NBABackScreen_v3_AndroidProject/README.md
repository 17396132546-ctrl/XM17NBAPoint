# 小米 17 Pro Max 妙享背屏 · NBA 实时比分 v3.0

## v3.0 专项优化
1. **默认避让后置双摄 + 自由缩放**：默认避让左侧摄像头区域（留白 35% + 缩放 85%），且可在主界面一键切换 `60%~95%` 缩放、`避左摄/避右摄/避上摄/避下摄/居中` 及 `留白 25%~48%`，即时生效并自动记忆。
2. **极简大字比分布局**：去掉背屏上的球队中文名字、去掉 ESPN/文字直播条、去掉 `3s/5s` 刷新频率与时间戳提示；队标与暂停/犯规收拢至上方，将整个安全区宽度与过半高度留给自适应超大号比分数字。
3. **保留实时同步与暂停/犯规**：后台继续支持 3 秒实时刷新，背屏仅保留精简节数时钟、`⏸ 暂停中` 提示以及队徽下方的 `暂X·犯Y·满` 状态。
